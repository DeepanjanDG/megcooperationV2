Accessibility Options in Browsers

How to enlarge text, change colours and turn on reading tools in your web browser and on your device.

Every modern web browser can enlarge text, change colours and read pages aloud. The steps below show how to turn those options on. They apply to this website and to every other site you visit.

The quickest option, in any browser

Hold Ctrl (Cmd on a Mac) and press + to zoom in, - to zoom out, and 0 to return to the normal size. This website also has its own A- / A / A+ text-size buttons and a High contrast switch in the bar at the very top of every page.

Settings by browser

Make text and images larger

  1. Hold down the Ctrl key (Cmd on a Mac).
  2. While holding it, press + to enlarge or - to reduce the page.
  3. Repeat until you reach a comfortable size. Press Ctrl + 0 to return to normal.

Set a permanent font size

  1. Open the ⋮ menu at the top right and choose Settings.
  2. Select Appearance in the left-hand list.
  3. Change Font size and Page zoom to your preference. These apply to every website.

Other accessibility options

  • Settings → Accessibility turns on caption preferences and lets you show a text cursor when browsing.
  • Extensions such as high-contrast themes and screen readers can be added from the Chrome Web Store.

Make text and images larger

  1. Hold Ctrl and press + to zoom in or - to zoom out. Ctrl + 0 resets the page.
  2. Or open the ⋯ menu at the top right and use the Zoom controls.

Set a permanent font size

  1. Open ⋯ → Settings → Appearance.
  2. Adjust Font size and Page zoom.

Read a page aloud

  1. Press Ctrl + Shift + U, or open the ⋯ menu and choose Read aloud.
  2. Use the toolbar that appears to pause, skip and change the voice or reading speed.

Immersive Reader

On article-style pages, press F9 to open Immersive Reader, which strips away the layout and lets you set text spacing, line focus and a picture dictionary.

Make text larger

  1. Hold Ctrl and press + to increase, - to decrease, and Ctrl + 0 to reset.
  2. To enlarge text only, and leave images at their original size, open ☰ → Settings → General and tick Zoom text only.

Set a minimum font size for all websites

  1. Open the ☰ menu and choose Settings.
  2. Under Language and Appearance → Fonts, click Advanced.
  3. Set Minimum font size to the smallest size you can read comfortably and click OK.

Use your own colours

  1. In Settings → Language and Appearance → Colours, click Manage Colours.
  2. Choose your text and background colours, then set Override the colours specified by the page to Always.

Reader View

Press F9 or click the page icon in the address bar to strip a page down to plain text, then adjust the font, width and colour theme.

Make text and images larger

  1. Hold Cmd and press + to zoom in or - to zoom out. Cmd + 0 resets the page.
  2. To set a permanent zoom level for every site, open Safari → Settings → Websites → Page Zoom and change the setting for All other websites.

Set a minimum font size

  1. Open Safari → Settings → Advanced.
  2. Tick Never use font sizes smaller than and choose a size.

Reader and VoiceOver

  • Press Cmd + Shift + R to open Reader, then change the font, size and background from the AA button.
  • Press Cmd + F5 to switch VoiceOver, the built-in screen reader of macOS, on or off.

Settings in your operating system

Changes made here apply to every application on the device, not just your browser.

Windows

Open Settings → Accessibility for text size, Magnifier, Colour filters, High contrast themes and Narrator. Press Win + + to start Magnifier and Win + Ctrl + Enter to start Narrator.

macOS

Open System Settings → Accessibility for Zoom, Display contrast, Larger text, and VoiceOver. Press Cmd + F5 to switch VoiceOver on or off.

Android

Open Settings → Accessibility for Font size, Display size, Magnification, Colour correction and the TalkBack screen reader.

iPhone and iPad

Open Settings → Accessibility for Display & Text Size, Zoom, Increase Contrast and VoiceOver.
