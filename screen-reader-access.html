Screen Reader Access

Assistive technologies, the screen readers this website works with, and tips for navigating these pages without a mouse.

Assistive technologies help people with visual, hearing, mobility and learning impairments to read and use a website. Screen readers convert text on a page into synthesised speech or Braille, so that visually impaired users can listen to and understand the content.

Screen reader access on this website

This website follows the Guidelines for Indian Government Websites and conforms to the World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA, to the extent feasible. Pages use proper headings, landmarks, lists, form labels and table headers so that they can be navigated reliably with assistive technology.

The information on this website has been checked with commonly used screen readers, including N.V.D.A., J.A.W.S., Narrator, VoiceOver and Supernova.

Using this site with a screen reader

  • Every page starts with a Skip to Main Content link. Activate it to jump past the topbar and navigation menu.
  • Use the heading navigation command of your screen reader (H in N.V.D.A. and J.A.W.S.) to move between sections of a page.
  • The main menu is a list of buttons and links. Press Enter or Space on a menu button to open its sub-menu, and Escape to close it.
  • Data tables carry row and column headers, so you can use table navigation commands to read a cell together with its heading.
  • Links that open an external website or a PDF document are labelled as such, so you know before you follow them.
